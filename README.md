# Web Application Project

This repository contains the source code for an application built with Next.js and integrated with the Gemini API.

---

## 🚀 Features
* **React Architecture:** Built for performance, scalability, and seamless modern web features.
* **Gemini API Integration:** Pre-configured to communicate with Google's generative AI models.
* **Environment Safety:** Secure API key handling via local environment variables.

---

## 🛠️ Tech Stack
* **Framework:** Next.js
* **Language:** JavaScript / TypeScript
* **Package Manager:** npm
* **AI Integration:** Google Gemini API

---

## 💻 Getting Started

Follow these steps to clone, configure, and run the application on your local machine.

### Prerequisites
Make sure you have **Node.js** (v18.x or higher recommended) installed.

### 1. Installation
Clone the repository (or navigate to the project folder) and install the required dependencies:
```bash
npm install
```

### 2. Environment Configuration
Create or update the .env.local file in the root directory and add your Gemini API Key:
```bash
GEMINI_API_KEY="YOUR_API_KEY"
```
### 3. Running the Development Server
Start the local server with the following command:
```bash
npm run dev
```
Once started, open http://localhost:3000 in your browser to view the application.
